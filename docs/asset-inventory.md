# Asset-Inventar

Dokumentiere hier jedes externe oder generierte Asset vor Veröffentlichung oder Druck.

| Datei | Quelle | Rechte/Lizenz | Verwendung | Status |
|---|---|---|---|---|
| `assets/logos/logo_thm.pdf` | THM | prüfen | Header links | vorhanden |
| `assets/logos/logo_iti.png` | ITI | prüfen | Header rechts, Default | vorhanden |
| `assets/logos/logo_bliz.pdf` | BLiZ | prüfen | Header rechts, optional | vorhanden |
| `assets/figures/main-figure.pdf` | eigene Darstellung | prüfen | zentrale Abbildung | offen |
| `assets/qr/qr-code.png` | selbst generiert | prüfen | Footer-Bar / Material-Link | offen |

## Hinweise

- Logos nur verwenden, wenn die Nutzung im jeweiligen Kontext freigegeben ist.
- Bei generierten oder externen Abbildungen Quelle, Lizenz und Erstellungsweg dokumentieren.
- QR-Code-Ziel vor Druck oder Veröffentlichung testen.
- Für wissenschaftliche Ergebnisse keine KI-generierten Datenplots verwenden, sondern echte Daten oder eindeutig gekennzeichnete Beispielgrafiken.
